# Mini Calendar

A simple and responsive digital calendar built with **HTML, CSS, and JavaScript** that displays the **current day, date, month, and year** automatically.

## Features

* Displays the current date
* Shows day, month, and year
* Updates automatically using JavaScript
* Responsive design
* Simple and clean UI
* No external libraries

## Technologies

* HTML5
* CSS3
* JavaScript

## Project Structure

```text
Mini-Calendar/
│
├── index.html
├── style.css
└── script.js
```

## How to Run

1. Clone the repository
2. Open the project folder
3. Open `index.html` in your browser

That's it! 🎉
