# To-Do List App

A simple **To-Do List web application** built with HTML, CSS, and
JavaScript. The app provides a clean interface for entering tasks and
adding them to a task list.

## Features

-   Add new tasks using a text input
-   Display tasks in a list
-   Simple and clean user interface
-   Task list structure supports completed/checked tasks
-   Custom icon included in the application interface

## Technologies Used

-   **HTML5** -- Provides the structure of the application
-   **CSS3** -- Used for styling and layout
-   **JavaScript** -- Handles the application's task functionality

## How to Run

1.  Clone or download this repository.
2.  Open the project folder.
3.  Open `index.html` in a web browser.

No additional installation or dependencies are required.

## How It Works

The application contains a text input where users can enter a task and
an **Add** button to add the task to the list.

The HTML page loads: - `style.css` for the application's styling. -
`script.js` for the task functionality. - `images/icon.png` for the
To-Do List heading icon.

The main task input uses the ID `input-box`, while the task list uses
`list-container`.
